# 可复制写作提示词

默认自动成稿时无需展示这些模板。用户希望复用提示词或分阶段协作时使用。

## 一次成稿

```text
请撰写完整文章。
体裁：【体裁】
主题：【主题】
可选补充：读者、用途、字数、语气、真实材料、范文。

未提供的风格和篇幅按体裁合理决定，不先问提纲。
内部完成构思、写作、按文体去AI腔、保真核对和修改，直接输出最终正文。
不要默认设问开头、整齐的建议分节和号召结尾；结构按内容需要安排。
缺少个人或事件事实时用少量清晰占位符，不编造数据、引语和经历。
虚构创作可自由设计情节，模拟现实报道则标明虚构示例。
```

## 构思与选角度

```text
围绕体裁【体裁】、主题【主题】，给出最多3个有实质区别的写作角度。
每个角度说明读者关切、核心表达、结构和所需事实材料。
不编造事实支撑角度。仅在我要求共同构思时停在这里等待选择。
```

## 起草

```text
按已选角度与材料生成完整稿件，匹配【用途／读者／语气／字数】。
开头进入主题，段落各有作用，结尾完成表达。
只把已给或已核验信息写成现实事实；其他信息留空或明确是假设。
```

## 编辑与核查

```text
检查文章是否符合体裁和主题，是否重复、空泛、语气失当或结构失衡。
按humanizer模块检查翻译腔、名词化、模板结构、虚假对称和空洞升华，重写问题段落。
核对事实、时间、称谓、数字、引用和叙述视角。
直接引语不改字，约／拟／试行等限定不丢失；改写不新增原文论点。
指出不能证实的具体说法，并删除、核验或保留明确待补项。
直接交付修订全文；只有我要求时另列修改说明。
```

## 后续改写

```text
将上稿改为【更口语／更正式／更简洁／指定新体裁】，
保留已确认的事实、核心诉求及【必须保留内容】。
篇幅要求：【字数或压缩比例】。
不新增未经确认的个人经历和事件事实，直接给改后稿。
```

## 只审查AI腔

```text
只审查下文，不改写。先判断文体，然后定位翻译腔、套话、
机械结构、语体不当及事实保真风险。
给出原句或位置、问题、影响程度、修改方向，并说明哪些表达应保留。
没有来源比对时将事实疑点标为待核，不推断AI生成概率。
```

## 人工查看重点

- 报道：日期地点、姓名职务、数据、采访与引语是否真实。
- 个人材料：原因、时长、行为、责任、落款与承诺是否符合本人意愿。
- 观点与科普：事实和观点是否区分，引用与专业解释是否准确。
- 文学创作：人物、视角、情节和风格是否符合创作意图。

这些检查是用户可选的编辑辅助，不构成自动成稿前的强制审批关卡。
